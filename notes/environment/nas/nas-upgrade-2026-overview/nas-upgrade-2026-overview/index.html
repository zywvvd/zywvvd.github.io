NAS 2026 升级总览：两周全模块复盘
Yiwei Zhang 2026年11月14日 晚上
2.4k 字 20 分钟 0 次   0 人   0 条
1794670200000

本文最后更新于：2026年11月14日 上午

从十月末新平台点亮到十一月中旬旧机停机，这次升级战线整整两周：基础设施、网络网关、博客服务、数据迁移、观测告警、工程治理六条线并行推进，累计上百次提交、六十余篇工作记录。前面的文章各自记录了单条战线的细节，本文按模块把整个升级的核心流程串成一张总图——只讲做了什么和为什么，细节请顺着各模块的专文链接深入。

模块一：基础设施

从裸机到八台虚拟机的全过程：

  • 装机与破案：PVE 9.2 + 双 SSD 组 ZFS mirror 一次装成；装机初期连续崩溃的根因是内存插槽兼容性，逐槽排查定位后换内存条解决——新平台前三天的故障后来再没出现过
  • 虚拟机全家桶：按职责切八台 VM（存储/应用/网关/观测/家庭/开发/支撑/模板），VMID 与内网地址尾号一致，终身免查表
  • 两条纪律：虚拟机 CPU 显式指定现代指令集等级（默认的保守档位会让新版 MongoDB 直接崩，全家统一补的课）；数据盘配 discard=unmap 让 guest 的 fstrim 穿透释放
  • 按需扩容：应用机内存因评论服务一次 OOM 从 6G 提到 10G，观测机为容纳新栈从 1G 提到 2G——都是在线扩、分钟级
  • 备份的诚实账：核查发现 VM 备份任务从未真正自动跑过（调度器曾挂死），按"备份归数据盘"的决策显式延后到搬盘批次，避免假就绪

模块二：网络与网关

  • 单端口收敛：公网暴露面从一长列服务端口收敛为极简几个——全部 web 服务共享一个 HTTPS 端口按 SNI 分发（详见网关篇）
  • 证书自治：通配符证书走 DNS-01 验证，百度云 API 自动增删记录，续期全自动——第三方证书服务从架构里退役
  • DNS 大扫除：泛解析一条顶掉过去十几条子域名记录；逐条考证后清掉十来条历史化石，其中一条差点误杀仍在线的服务——删记录前先验证线上引用的教训
  • WireGuard 回国代理：人在外面连隧道即达全家内网；上线时修过一个端口映射错位的静默丢包问题
  • hairpin 回流：家里家外同一套域名地址，实测全通，配置零分歧

模块三：博客服务层

两周里最密集的战线——博客的每个动态部件都搬了家、升了级：

  • 评论系统：跨一年半的大版本升级迁移，一千余条评论逐条对齐；服务端配置全量对齐过程中挖出三个隐藏缺失（登录签名钥静默失效、社交登录列表拖慢全站、头像走境外源），逐一修复后管理端加载从数秒降到两秒内
  • 访问统计：跨两个大版本迁移，四十六万事件百分百落位；切换时间差造成的统计缺口用跨版本手工合并补齐；顺带做了地理显示口径修正和面板图标国内化
  • 图床：四十余 GB 图片资产整体迁移，站内一万七千余处引用全量切换到新子域名，跨域头补齐后搜索索引等跨域场景一并打通
  • 一言服务：版本已是最新的上游终版，真正的问题在语料同步源被墙——换镜像源后一万一千余句语料恢复自动更新
  • 静态站本身：Hexo 跨一个大版本升级（沙箱全量生成对比零差异后上线）、主题合并上游两年积压的更新并把五十三个混杂提交重写为十个功能提交、站内搜索从 27MB XML 重构为分片索引、发布流固化为一条命令

模块四：数据与家庭服务

  • 网盘：跨四个大版本的迁移取舍与一次上游发布事故的考古，详见 Nextcloud 篇
  • 家庭相册：三库（关系库/文档库/对象存储）全量迁移，逐项对账一致，手机 App 无感切换
  • 服务裁撤：确认不再使用的知识库、笔记、同步观影三个服务全链路下线（容器/路由/监控/旧实例四处清干净，数据 dump 留档可回滚）
  • 旧机对账定版：旧机器上三十余项现役组件逐一定性——哪些延续（多数已在新栈就位）、哪些随迁移消亡，形成退役台账

模块五：观测与告警

从零到全栈观测，详见观测栈篇：

  • 拨测三十项全覆盖（虚拟机/服务/底层/对外链路）+ 宿主机硬件心跳（阈值越界静默即告警）
  • 指标三十天轮换，Grafana 内部全量板
  • 公开健康页：采集层脱敏管道 + 零依赖单文件页面，访客看得见健康、看不见内网

模块六：工程治理

最不显眼但决定长期成本的一条线：

  • 配置仓库化：二十六个服务配置各自成独立 Git 仓集中托管，数据/大文件/密钥排除在外；每日凌晨自动快照比对漂移——任何一台机器炸了，配置可以从仓里完整重建
  • 发布流一键化：博客发布从五步手工操作收敛为一条命令（构建+索引+同步+部署）
  • 密钥档案：全链路凭据集中到仓外加密档案，页面泄露过的恢复码全部轮换作废
  • 文档体系：迁移全程三十余篇编号工作记录 + 活状态 README——每个决策有出处、每次踩坑有归档，事后写博客时全部素材可考

旧机退役

确认迁移完成的服务分批停机：评论、一言、旧监控、统计、网关壳、旧网盘三件、家庭旧套件六件、裁撤服务残留，外加定时脚本清理。停机后跑全站验证，十项核心服务全绿零破坏。旧机上仅存"数据未迁的小服务 + 备份链 + 公网 DDNS"三类等待搬盘批次，搬完拔电入库。

尾声

两周的改动密度是建站五年之最，但真正的产出不是"换了一台机器"，而是每一层都有了可维护的形态：配置在仓里、决策在文档里、变更在提交里、健康在曲线上。剩下的机械盘搬完，这次升级就画上句号了。
